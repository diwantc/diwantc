## Pourquoi c'est important ?

Quelqu'un vous appelle et dit être de votre banque : « Il y a un problème sur votre compte. Nous vous avons envoyé un code, lisez-le-moi pour que nous le réglions. » Ou vous recevez un message WhatsApp du numéro d'un ami : « Je t'ai envoyé un code par erreur, renvoie-le-moi. » Dans les deux cas, l'escroc veut votre code de validation. Dans cette leçon, vous apprenez pourquoi ne jamais le donner, et vous protégez votre compte WhatsApp.

## L'idée

Un code de validation est un nombre que vous recevez par SMS ou par e-mail quand vous vous connectez à votre compte. On l'appelle aussi code à usage unique (OTP). Votre mot de passe et le code fonctionnent ensemble : quelqu'un qui ne connaît que l'un des deux ne peut pas entrer.

L'escroc connaît peut-être déjà votre mot de passe ou certaines de vos informations : il ne lui manque que le code. C'est pourquoi il essaie de vous le faire lire. Celui qui obtient votre code peut entrer dans votre compte, prendre votre argent ou vos données, et se faire passer pour vous.

La règle est simple : **le code est pour vous seul.** Quiconque vous le demande est un escroc, même s'il dit être de la banque ou d'un organisme officiel, et même si la demande vient du numéro d'un ami ou d'un proche.

Sur WhatsApp, vous recevez un code d'inscription de 6 chiffres, par SMS ou par appel, quand votre numéro est enregistré sur un téléphone. Celui qui l'obtient peut prendre votre compte, puis écrire à vos amis et à vos groupes en votre nom.

## Étape par étape

### Si quelqu'un vous demande le code

1. Ne le lisez pas et ne l'envoyez pas. Raccrochez, ou arrêtez de répondre.
2. Si votre compte vous inquiète, appelez vous-même la banque à un numéro de confiance, par exemple celui de votre relevé de compte ou de l'application de la banque. N'appelez pas le numéro donné par votre interlocuteur, et ne vous fiez pas au nom de la banque affiché : un escroc peut faire croire qu'un appel ou un message vient de la banque.
3. Si la demande vient du numéro d'un ami, appelez-le vous-même au numéro que vous aviez déjà enregistré, pour vérifier.

### Activez la vérification en deux étapes dans WhatsApp

La vérification en deux étapes protège votre compte par deux éléments à la fois : le code que vous recevez et un mot de passe que vous choisissez. Il devient plus difficile, pour quelqu'un qui a pris votre code, d'enregistrer votre numéro sur un autre téléphone. Mais c'est une protection en plus : ne donnez pas le code, même après l'avoir activée.

**Android :**

1. Ouvrez WhatsApp, appuyez sur les trois points ⋮, puis sur Paramètres > Compte > Vérification en deux étapes.
2. Activez l'option Activer la vérification en deux étapes.
3. Créez un mot de passe fort que vous retiendrez, d'au moins 8 caractères avec au moins une lettre et un chiffre, puis saisissez-le une seconde fois pour le confirmer.
4. Saisissez une adresse e-mail que vous pouvez ouvrir et appuyez sur Suivant, ou appuyez sur Ignorer.
5. Appuyez sur Faire confiance à cet appareil ou sur Ignorer.

**iPhone :**

1. Ouvrez WhatsApp, appuyez sur Vous, puis sur Compte > Vérification en deux étapes.
2. Suivez les étapes 2 à 5 comme sur Android.

Si vous oubliez le mot de passe au moment de vous connecter, vous pouvez vous vérifier autrement, par exemple avec un code reçu par e-mail ou par SMS. Sinon, vous devrez peut-être attendre quelques jours pour réinitialiser votre compte, et certains de vos messages pourront être supprimés.

WhatsApp remplace le code PIN, un nombre secret de 6 chiffres, par un mot de passe. Si vous voyez « code PIN » au lieu de « mot de passe », suivez ce qui s'affiche sur votre écran.

> Le mot de passe de la vérification en deux étapes est comme le code de validation : ne le donnez à personne.

## À vous de jouer

Ouvrez WhatsApp maintenant et activez la vérification en deux étapes avec les étapes ci-dessus. Si elle est déjà activée et que vous ne vous souvenez plus du mot de passe, créez-en un nouveau tant que vous êtes connecté : l'ancien n'est pas nécessaire.

## À retenir

- Le code de validation est pour vous seul. Quiconque le demande est un escroc, même s'il dit être de la banque.
- Celui qui obtient votre code peut entrer dans votre compte, prendre votre argent ou vos données, et se faire passer pour vous.
- Activez la vérification en deux étapes dans WhatsApp, choisissez un mot de passe que vous retiendrez, et ne le donnez à personne.
