# Security policy

Please **do not** report security problems in public issues.

Report them privately through GitHub: open the repository's **Security** tab
and choose **Report a vulnerability**. Only the maintainer can see the report.

Include what you found, how to reproduce it, and what could go wrong.
You will get an answer as soon as possible.

The site is static and collects no personal data. The parts most worth
checking are the CI workflows (`.github/workflows/`) and, once it is added,
the error-report form endpoint (`functions/`).
